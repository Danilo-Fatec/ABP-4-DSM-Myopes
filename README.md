# 📑PRODUCT BACKLOG
|  Requisitos Funcionais       |                              |                              
|------------------------------|------------------------------|
RF01: O sistema deve exibir telas separadas para Área Queimada, Foco de Calor e Risco de Fogo, com tela inicial e logo do projeto.
RF02: O sistema deve permitir filtrar os dados por Estado (com seleção de cidade) ou por Bioma, além de um período, por meio de radio box, caixas de seleção e botão "Filtrar".
RF03: O sistema deve apresentar a resposta de acordo com a escolha do usuário (Foco de Calor, Área Queimada ou Risco de Fogo), com caixa de zoom no mapa e tela de gráfico com os dados filtrados.
RF04: O sistema deve armazenar os dados do projeto em um banco de dados com as tabelas principais estruturadas e relacionadas por FK.

|   Requisitos Não Funcionais  |                                                                                                                 
|------------------------------|   
RNF01: O sistema deve ser responsivo, com layouts específicos para PC e celular.
RNF02: A interface deve ser simples e intuitiva, com menu suspenso no PC e botão "Hambúrguer" que abre o menu no celular.
RNF03: O banco de dados deve garantir a integridade referencial dos dados por meio de chaves estrangeiras (FK).
RNF04: O sistema deve manter identidade visual consistente (logo, cores e componentes) em todas as telas, seguindo os wireframes do Figma.
-----------------------------------------------------------------------------------


|   USER STORIES  |                                                                                                                 
|------------------------------| 
US01: Como usuário, quero acessar uma tela inicial com a logo do projeto, para entender do que se trata o sistema e navegar até as demais telas.
US02: Como usuário, quero visualizar a tela de Área Queimada, para saber quais regiões foram atingidas por queimadas.
US03: Como usuário, quero visualizar a tela de Foco de Calor, para identificar onde há focos de calor ativos.
US04: Como usuário, quero visualizar a tela de Risco de Fogo, para saber quais regiões têm maior probabilidade de incêndio.
US05: Como usuário, quero escolher entre filtrar por Estado ou por Bioma (radio box), para consultar os dados no recorte que me interessa.
US06: Como usuário, quero selecionar uma cidade (quando filtro por Estado) ou um bioma (quando filtro por Bioma), para refinar minha consulta.
US07: Como usuário, quero selecionar o período da consulta, para analisar os dados de uma data específica ou de um intervalo.
US08: Como usuário, quero clicar no botão "Filtrar" e receber a resposta de acordo com a variável escolhida (Foco de Calor, Área Queimada ou Risco de Fogo), para ver apenas o que pedi.
US09: Como usuário, quero visualizar um gráfico com os dados filtrados, para comparar e entender melhor as informações.
US10: Como usuário, quero usar a caixa de zoom no mapa, para ver com mais detalhe a região de interesse.
US11: Como usuário de celular, quero um botão "Hambúrguer" que abre o menu, para navegar com facilidade em telas pequenas.
